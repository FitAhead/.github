# FitAhead

### 오늘의 내가 미래의 나를 바꾼다

**운동·식단·수면·음주 등 생활 기록을 바탕으로, 1주일~몇 달 뒤 내 몸의 변화를 캐릭터로 미리 보여주는 건강 동기부여 앱**

</div>

---

## 📌 개요

FitAhead는 단순한 운동 기록 앱을 넘어, 오늘의 생활 기록이 **미래의 나에게 어떤 변화로 이어질지**를 캐릭터 시뮬레이션으로 보여주는 동기부여·건강 어플리케이션입니다.

기존 앱들이 횟수·칼로리·체중·중량·루틴을 기록하는 데 그친다면, FitAhead는 그 기록을 바탕으로 미래의 신체 변화를 **시각적으로 예측**하여 지속적인 동기부여를 제공합니다.

> 운동과 건강에 관심 많은 현대인들의 노력을 미리 보여줍니다.

## 🎯 정체성 / 차별성

- **(메인)** 운동 기록 + 캐릭터 시뮬레이션 + 몸 변화 예측
- **(확장)** 커뮤니티 · 헬스장 연동(소개, PT) · 지역/동네별 칼로리 경쟁 · 의류 등 판매 연계

목표 시장은 국내를 포함해 미국·일본 등 해외 우선 출시도 검토 중입니다.

## 🔍 문제 인식

운동·다이어트·건강에 관심 많은 사람들이 겪는 대표적인 고민:

1. 지금 내가 하는 운동이 제대로 되고 있는지 모르겠다
2. 오늘 운동하고 식단을 조절해도 바로 몸 변화가 보이지 않는다
3. 체중·칼로리·횟수를 기록하다 지친다 (동기부여가 약하고 돌아볼 일이 없다)
4. 혼자 운동하고 다이어트를 지속하는 게 어렵다
5. 신체·운동·식단에 따라 성과가 다른데, 커뮤니티에는 이런 개별성이 반영되지 않은 결과만 존재한다
6. 신뢰할 만한 정보, PT 등에 대한 정보가 부족하다

## 💡 해결 방안

**기록 + 캐릭터 시뮬레이션**으로 가시적 성과를 보완하고 동기부여를 제공합니다.

| 분류 | 가시적 변화 기간 | 활용 |
|---|---|---|
| 체중 경향 | 1~2주 | 수치 데이터 예측 |
| 체지방 감소/증가 경향 | 2~4주 | 수치 데이터 예측 |
| 운동 수행감·근력 변화 | 2~4주 | 운동량 데이터 예측·보완·추천 |
| 근육량 변화 | 3~8주 | 캐릭터 시뮬레이션 적용 |
| 가시적 체형 변화 | 6~12주 | 캐릭터 시뮬레이션 적용 |
| 혈압 개선 (심혈관·대사) | 4~12주 | 운동량 데이터 예측·보완·추천 |

추가로, 건강 정보 취합 + AI 활용 + 데이터 축적을 통해 **개인 맞춤형 정교화**를 지향하며, 목적별 헬스장 분류(건강·자세교정·바디빌딩·기능성 등), 지역 경쟁, 의류 핏 미리보기, Apple Watch·건강 앱 연동 등으로 확장합니다.

## 🔄 핵심 루프

```
기록 → 예측 → 실제 비교 → 보정 → 추천
```

1. 신체 입력 (키, 몸무게, 목표, 체감 상태)
2. 현재 캐릭터 생성
3. 일상 기록 (식단, 운동, 숙면 등)
4. 현재 vs 미래 캐릭터 비교
5. 세부 건강정보 확인 / 해부학 모드 확인
6. 실제 변화 기록 → 예측 vs 실제 비교
7. 개인화 보정 → 다음 루틴 추천 (커뮤니티 + AI)
8. 설정 목표 대비 현재 상황 및 필요 운동량·시간 제시

## 🕹️ 캐릭터의 역할

- 사용자의 현재 몸 상태를 보여주는 **아바타**
- 운동·식단·습관 기록을 반영하는 **대시보드**
- 1주일 뒤 예상 변화를 보여주는 **시뮬레이션 대상**
- 사용자에게 피드백을 주는 **코치**
- 지속 사용을 유도하는 **성장 요소**
- 커뮤니티·SNS 공유의 **시각적 카드**

## 🗂️ 데이터 구조

1. **필수 정보** — 키, 몸무게, 나이, 성별, 목표
2. **선택 정밀 정보** — 체지방률, 골격근량, 기초대사량, 인바디
3. **체감 신체 정보** — 복부, 상체, 하체, 부종, 체력, 피로도, 컨디션
4. **운동 기록** — 종류, 부위, 시간, 강도, 빈도
5. **식단 기록** — 음식 카테고리, 대략 섭취량, 단백질, 야식, 음료 등
6. **습관 기록** — 수면, 물, 음주, 흡연, 걸음 수, 외식, 야식
7. **예측 데이터** — 1주일 뒤 예상 체지방·체력·근육·회복력 변화
8. **실제 변화 데이터** — 체중, 눈바디 게이지, 컨디션, 체력, 부종, 인바디(선택 입력)
9. **예측과 실제 차이** — 예상보다 빠름 / 느림 / 비슷함
